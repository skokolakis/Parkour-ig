# Parkour Implementation Guide (FHIR R4)

A hobby **HL7 FHIR Implementation Guide** for recording parkour training: athletes, coaches, training spots, sessions, movement performance and injuries. It's written in [FHIR Shorthand (FSH)](https://build.fhir.org/ig/HL7/fhir-shorthand/), compiled with [SUSHI](https://fshschool.org/), and published with the HL7 IG Publisher.

**Live build:** https://build.fhir.org/ig/skokolakis/Parkour-ig/
**Build log:** https://build.fhir.org/ig/skokolakis/Parkour-ig/build.log

## Disclaimer

This is a personal learning project. It is not an official HL7 specification and is not intended for clinical use.
